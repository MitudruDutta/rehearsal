## The usual path

1. [Add an application](/guides/add-an-application), once for each application.
2. [Build a practice world](/guides/build-a-practice-world), once for each release of the application that you want
   to test against.
3. [Evaluate an agent](/guides/evaluate-an-agent) on the `dev` jobs, and [read the results](/guides/read-results).
4. [Improve the agent](/guides/improve-an-agent), by hand or with the improvement step.
5. Evaluate the old and the new version on the `holdout` jobs, and
   [compare them](/guides/compare-agents-and-runs).
